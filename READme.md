# Herramienta de diagnostico de Clusters

## Proposito 
El proposito de la herramienta es hacer una version versatil para el analisis de los clusters estrayendo información, generando reportes y aplicando cambios. 

## Componentes
- elementos.py: Clases que conforman los proyectos y contienen los metodos disponibles para cada instancia.
- explorador.py: Itera los componentes de los proyectos dependiendo de la profundidad que elijas.
- analysis.py: Contiene las clases que generan las recomendaciones, reportes o los ajustes en distintos formatos. 
- aplicador.py: Contiene los metodos y clases responsables de aplicar cambios. Este lee y escribe en GCP por lo que se debe de usar con cuidado.
- diagnostico.py: Script principal, aqui se tienen los ajemplos de uso para mostrar como se usan sus funciones base.
